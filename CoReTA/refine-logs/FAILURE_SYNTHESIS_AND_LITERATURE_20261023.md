# 从复核失败到可检验的改进：近期实验与文献复盘

日期：2026-10-23。仅复核已有记录和检索论文；没有新增模型实验或修改运行架构。

## 摘要

近期实验已把问题定位到知识进入共同解答之后的解释、应用和复核，但没有隔离唯一原因。004出现正确约束与虚构解释捆绑、跨源联合推理被误拒；034出现原件可见、甚至被引用，却仍否认原报告内容。多个候选干预只改变职责提示或呈现方式，未给判断引入独立依据或更可靠执行机制。已有研究分别改善了上下文诱导、文本支持关系判定、形式推理和协作动作验证；这些效果都有明确适用条件。现阶段应优先检验独立证据判断能否成立并在应用中保留，再决定是否重构架构。

## 1. 研究问题与方法

RQ1：近期失败发生在哪里，已知现象与因果解释分别是什么？RQ2：已有方法是否改善过相同或相邻问题，靠什么条件？RQ3：在 API 条件下，哪种后续工作能够真正改变判断能力而非重复提醒？

读取 selective-application、discriminating-check、simple-review-validation、evidence-focus-validation 的结果与语义复核报告，以及历史续跑证据链。检索从验证方法、失败反证、多 agent 社会影响、符号/环境验证几个方向展开，核验论文正文。下文是针对本项目瓶颈的定向综述，不声称覆盖所有多 agent 文献。人工实验标签沿用现有执行者审阅，未经新的独立盲评。多次重复同一道开发题不视作独立任务样本。

## 2. 实验到底证明了什么

| 实验 | 主要结果 | 支持的判断 |

|现有复核与简明核对，32次|004明确误拒7/8对3/8；034均0/8发现损失|简化有局部改善信号，关键语义瓶颈仍在|

|选择性应用，24次|两组均选项10/12、知识应用完整8/12；004均0/2，034语义均0/2；控制均8/8|增加选择性应用提醒未观察到增益；模型并非一概不会部分采用|

这几批多数是固定输入下的环节诊断，不能汇总成CoReTA整体胜率。最新批次是人工混合建议，测的是面对这种建议时的表现，不是团队自然产生错误建议的频率。

004的自然D0续跑确有汽车约束促使Z改为儿子并被保留；不能说架构从未起作用。034仍选对Cedar，但削弱Pine危险报告；不能用选项正确掩盖知识损失。普通讨论在早期任务成功，也不能从这些没有同步普通讨论对照的固定诊断推断其成功原因。

### 2.1 已定位的三类错误

第一，证据内容被错误解释。034原件明确报告Pine危险。持有完整原件的A1仍接受“只报告北漂、没有明确危险评价”。保留报告说了什么，与认证现实绝对危险，是不同判断；此处二者被混淆。

第二，事实、附带猜测与答案捆绑。004接受汽车约束，同时接受原文没有的“儿子是乘客”；再用线索权重维护父亲答案。在候选完备、线索指同一肇事者及普通车辆分类的条件下，汽车、年龄、性别应共同排除候选。车主与驾驶者酒精含义、父亲具体责任叙事仍有单独歧义，不能将整篇理由算作无争议金标准。

第三，复核把执行建议当作建议成立的证据。自主检验问的是“是否正确地按O3/O5降为推断”，备选没有覆盖“原报告本来就明确说危险”。于是应用、检查和选择可以一致地维护错误。

这些是可见行为，不等于已经证明锚定、迎合或能力不足是唯一原因。局部比较移除大段历史仍失败，说明历史长度并非必要条件；持有原件也失败，说明补一个原件持有者确认并不充分。

### 2.2 为什么反复改了仍没收益

最近K只是职责前缀变化，旧TRY本来就允许Partial adoption。自主检验没有执行外部测试或获得新证据，自由复核基线也共用提问/备选字段。它们更多测试“提醒是否有效”，尚未实现更独立的判断过程。我们对行为缺口的描述越来越准确，但曾过早把描述转成指令，当成解决机制。

来源权限、字段完整、版本管理能保证运行可追踪，却不能保证语义判断可靠。最新24次全部格式通过仍语义失败，故格式不是该批主因。反过来，早期缺字段确实损害了实验完整性，不能忽略。

尚缺的关键因果比较：相同资料、相同任务，在没有错误建议时能否正确判断；加入建议后是否改变；独立判对以后是否在应用中再次丢失。这三个问题目前没有被完整地配对隔离。

## 3. 文献：改变判断条件，与继续要求认真检查的区别

### 3.1 独立验证与文本依据核对

[Chain-of-Verification（ACL Findings 2024）](https://aclanthology.org/2024.findings-acl.212.pdf)让验证回答不见原答案，减少重复原幻觉；MultiSpanQA F1为0.39→0.48。主实验是闭卷，不能直接证明我们的问题会修复。[Factored Verification（WIESP 2023）](https://aclanthology.org/2023.wiesp-1.13.pdf)则直接检验给定摘要对断言的支持：ChatGPT在HaluEval检测上，普通CoT61.2%、单提示拆解63.3%、多提示拆解71.2%。后者更贴近“资料已给出但解释错误”，但检测仍不可靠，不能成为真值裁判。

两篇共同启发是改变验证者看到的信息及判断范围。我们的局部片段实验并未完整实现这种隔离：它仍是在已有修改框架下评价前后版本。另一方面，验证问题仍可能由错误草稿诱导，简单移除答案不保证发现遗漏。

[Verify-and-Edit（2023）](https://arxiv.org/pdf/2305.03268)用检索证据修改推理，再生成答案；2WikiMultiHopQA上CoT-SC EM27.7%，Google检索33.6%，数据集材料37.2%。它增加了证据来源，且一致性选择器可能漏掉一致错误，不能理解为多问一次就有效。

[Large Language Models Cannot Self-Correct Reasoning Yet（ICLR 2024）](https://arxiv.org/pdf/2310.01798)在去掉答案真值停止信号后观察到修订反而降低准确率。它支持同时记录错→对、对→错并匹配采样预算；其早期模型、无外部反馈条件不构成对当前所有自纠错方法的否定。

### 3.2 可执行验证：更强反馈，也有明确边界

[Communication and Verification in LLM Agents towards Collaboration under Information Asymmetry](https://arxiv.org/html/2510.25595v1)与主线最接近：成员拥有不同约束，环境验证器使用约束闭包筛选动作。表中GPT-4o双向通信成功率51%→80%；每步采4候选，收益包含额外采样。它依赖结构化环境，不能直接套到开放域材料理解。

[Logic-LM](https://aclanthology.org/2023.findings-emnlp.248.pdf)和[LINC](https://aclanthology.org/2023.emnlp-main.313.pdf)让API模型形式化，再由求解器推理；支持在004类约束组合中避免“多数线索压过硬约束”。但错误翻译也能得到逻辑一致的错误答案。034首先是原报告含义识别，不能把这一步交给求解器就认为解决。

上述三篇共同提供的是可验证任务上的改进路线，而非通用理解能力保证。采用这种路线需接受任务范围，并把自然语言到约束的忠实性单独评价。

### 3.3 降低意见影响与从数据学习

[Measuring and Mitigating Identity Bias…](https://arxiv.org/html/2510.07517v1)去掉自我/他人标签可降低身份偏差，但附录D准确率有升有降。不能据此把匿名化当作质量提升；知识来源仍需保留以便追溯。[Talk Isn’t Always Cheap](https://arxiv.org/html/2509.05396v1)观察到混合强弱模型仍会正确转错误，也提醒我们换异构模型并非充分解法。

[CONSENSAGENT（ACL Findings 2025）](https://aclanthology.org/2025.findings-acl.1141.pdf)报告了多任务改善，但其提示优化器使用训练集真值构造改写样本并微调GPT-4o；论文也比较了泛泛要求改提示与未训练的上下文优化。它不能被概括成“换一句更好的提醒”。这提供了无需本地GPU的学习路线先例，实际平台支持、费用及数据规模需另行确认，不能照搬历史价格。

## 4. 综合判断与后续选择

RQ1：已经定位到证据解释、联合推理、建议影响和应用保留这些具体位置，但没有隔离主要因果因素；现有候选干预未获支持。不能说完全没找到问题，也不能说已经找到唯一根因只差实现。

RQ2：已有方法确实改善相邻问题。独立验证改善部分事实核对；可执行验证改善结构化推理和信息不对称协作；训练可改变提示优化能力。没有检索到可直接保证解决我们自然语言混合贡献问题的通用方法。

RQ3：优先做一次能决定方向的能力定位，而非再次扩充工作流。固定同一任务和资料，区分无建议独立判断、错误建议影响、判定结果进入应用三个位置。独立判定应只接触原资料和中性任务问题，不接触“应该怎么修”的建议。诊断阶段人工指出争议句只能算上限干预；正式协作必须单独检验成员是否自主定位相关内容。

若无建议也失败，只能先说明该输入与调用条件下判断失败，还应检查问题措辞、任务歧义和材料表示；不能直接判定基础模型没有能力或必须训练。若独立判断可靠而建议使其退化，才有较强理由检验隔离判断再合并的交互。若判断正确但应用仍错，应重点检查应用及版本选择。三种结果可能同时出现，导向不同设计，不把它们都命名为“再加反馈”。

下一轮不应仅重复004/034；需要未参与设计的新案例、正确建议、错误建议、合理联合推导，以及明确的原报告/现实真实性区分。记录最终质量、正确知识保留、错误附带内容接纳、纠正与损害迁移，以及成本。对比预算相同的普通讨论和独立作答/核对。尚未冻结或运行这一实验。

## 5. 项目决定

不将最新K提示接入主架构，不宣称RL已经被证明必要，不立即堆叠第三层复核。保留中间解答、实际试用和版本证据链作为研究载体。接下来需要改变的是产生判断的条件，并先证明该变化能改善具体判断；之后再检验这些判断是否帮助多成员共同解题。

## 6. 二次审核修正

本报告可作为失败复盘与候选路线依据，尚不是可直接执行的新实验方案。需要修正四点：

1. “多数修改只改提示”准确描述最近筛查，不代表此前中间产物、试用、版本选择等架构没有实现；也不意味着提示干预天然无价值。选择性应用PLAN明确把它定义为提示能力探测，不能事后将一次负结果等同于设计或执行违规。问题在于此类筛查连续负结果后，应转换研究决策。
2. 现有最强证据是具体判断和修订失败。“没有独立判断”仍是解释与候选干预，不能升级为已确定根因。局部比较已经移除了许多历史，新增隔离条件必须说明与它的实质差别。
3. 单Agent能力定位只是辅助诊断，不能替代主线。后续机制必须证明它比同预算普通讨论更有效地利用分散知识，并允许正确建议改变旧解答；不能靠普遍拒绝建议保住旧答案。
4. 034当前选项没有改错，知识损失是真实过程问题，但对任务收益的影响尚未被该例证明。评价应分别记录结果、证据忠实性、纠错及误改，不能把理由缺陷全部算成完整任务失败。人工正确判断回填只能用于定位下游应用瓶颈，不能计自主机制效果。

在新增请求前，先对齐既有实验缺失的对照，确认每个条件会改变哪个设计决定。人工提示争议点、资料集中、额外采样、模型升级均应单独标记；不能将其收益直接归功于协作协议。

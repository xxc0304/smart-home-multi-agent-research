# 专家优势如何转化为团队表现：实验计划 v0.8

2026-10-31。用户报告下周一（2026-11-02）可获得GPU；型号、显存、系统与可用时长尚未核实。本次按experiment-plan制订实验与判断规则，按research-review本地两轮自审；不是独立评审，也没有启动训练或推理。v0.7及更早快照保留，本文件的固定副本为现行唯一计划入口。R22按用户选择：训练及独立资格测试只关注答案，理由/来源留后续讨论需要时请求。

## 1. 研究主线与证据边界

**总问题：具有真实任务优势的成员，为什么有时不能提高团队表现，甚至被团队拖累；哪些调整能改善优势利用，同时保留有益纠错？**

MuSiQue是首个设置，同底座任务LoRA是构造能力差的手段，四轮开放讨论是观察环境。它们不是总命题的限定条件。专家自身错误、分享、理解/应用、同伴干扰、最终整合是查证位置，不是已经证实的原因，也不要求每处都单独跑实验。

当前有数据、离线四轮状态机与评分工具；近期任务专家训练、C校准、新任务团队轨迹均为0。旧CoReTA实验存在，但不替代此设置的证据。已结束的D8/训练12质量核读不重开；1796题仅过滤已知4条问题，不称其余训练样本已清洗。

### 拟检验的主张（不是已有结论）

| 主张 | 最低证据 | 反驳或替代解释 |
|---|---|---|
| C1：经校准的优势在进入团队后存在可重复、可定位的损失，其中一个可观察瓶颈对受控干预有稳定响应 | 固定E独立校准；普通团队/初答投票/E无消息配对；真实过程定位；针对性干预与简单控制；留出复验 | 只有投票低于E不能证明互动损害；同样自发漂移、格式退化、资料缺桥接都可能解释 |
| C2（条件性）：针对已识别瓶颈的最小调整可改善最终净效用，并不过度牺牲有效纠错 | 与普通团队、简单基线、E单独及额外思考比较；全样本净效果和E初错切片；成本；冻结后的确认 | 一律服从E可能只提高正确保留，却阻断纠错；普通提醒或增加推理即可解释收益 |

仅复现“团队不及强成员”或增加失效类别，不足以成为本论文的主要增量。C1要推进到受控响应及适用边界；C2不是强制要求新架构。若证据改变，应改变贡献形态，不能预填正结果。

## 2. 研究问题 → 贡献 → 实验 → 判据

| 研究问题 | 拟议贡献 | 必需实验 | 成功/失败判据 |
|---|---|---|---|
| Q0：E是否真有任务优势？ | 建立可信研究对象，属于前提 | B/E仅答案V选模、C160独立配对；答案EM/F1与技术完整性 | C答案优势有实际意义且不确定性支持；只有格式或训练集提升不够。区间跨0记未建立，不当作无能力的证明 |
| Q1：损失在独答、互动还是最终读出？ | 分清损失位置及有益纠错，支持C1的现象部分 | 同题E初答、四初答投票、四轮团队、E无消息；记录每人成员终答 | 能分开报告不同差值、正误转移与不确定性；小批无事件仅说明未观察到，不强行归因或换题 |
| Q2：哪个可观察瓶颈可被干预改变？ | 可证伪的过程解释，C1核心 | 固定历史分叉、最多1–2个操作、适当通用/布局控制；全过程续跑及新题复验 | 定向操作在预测位置改变行为/损益且超出简单控制；仅个别成功或局部终答提升不足以证明团队机制 |
| Q3：调整值得使用吗？ | C2或分析结论的可迁移边界 | 冻结操作后留出题、重复顺序/采样，至少一个独立新配置的条件性扩展；正确保留与纠错、成本 | 净效应和纠错损失均满足预定实用标准；若普遍服从E即可解释、收益不复现或纠错代价过大，修改或放弃方法主张 |

- **T1796候选**：data/expert-training-answer-only-20261031/train.messages.jsonl（仅短答案监督）；仅在实际训练manifest登记后启用。原T1800保留不改。
- **V200**：训练侧选模与最多一次有根据的训练修订，不用于专家正式资格；V分组/任务覆盖偏差见TRAINING_SETUP.md。
- **C160**：一个最终候选对B独立核验，不据C改超参、不按C错题再训。优势证据不足时不封专家；如需额外独立校准，先另定未使用样本、预算和用途，不自动挪H或从D挑对题。
- **D80**：开发题，按固定原顺序先8、累计32；需要时使用余48，不按是否专家受损换题。D8可检技术/现象覆盖，D32可选候选，均不能支撑原因普遍性或微小效应确认。
- **H确认候选**：本轮不看题/标签。只有开发后的主对比、操作、N、分析和预算冻结后，才按预定抽样取确认样本。D、V和反复看过的旧案例不算独立确认。

所有成员推理时见相同问题和完整段落；没有gold、分解答案或特供桥接信息。保留E当题错误与B正确。官方评分保留全部预定题和原分母，已知资料限制单列敏感性解释，不在看结果后改gold或删除失败题。自动格式失败、技术缺失与答案错误分开报告。

**统一条件**：同底座/量化、任务输入、初终答格式、阶段输出上限及thinking设置；预先记录seed、初答与发言顺序，模型/adapter和实际完整模板长度。不同分支复用相同初答；不能用事后正确者重新指定E。推理温度等数值依实际后端短步预检后、正式C/D生成前冻结；初答不能三个B都用完全相同确定性请求制造假多样性。可采用同一非零采样策略，或明确报告确定性B同质性；不为制造损害故意调差B。

## 4. 五个核心实验块

### B0：构造并独立验证任务优势成员（必须）

**检验**：有限任务SFT能否使E在未见题上优于B，而非只改善输出格式。

一个具备聊天能力的Qwen起点B，E=B+一个任务LoRA；3个普通成员是B独立会话。无需四套同时驻显存。4B/8B及精度按实际机器与完整上下文验收决定，不用卡尚未到位假定4090。训练方案沿TRAINING_SETUP.md：1796训练/V200，初始1epoch，最多两次主要训练尝试，仅V选候选。输入问题和全部资料，assistant仅原短答案，不训练支持编号、解释或协作。答案微调仍可能连带改变其他行为，不能称只改了能力。

先完成最小训练执行器（assistant-only loss、无静默截断、保存/重载、模板长度）。GPU到位先短步验收，再测全长样本的训练步耗时/显存和完整讨论历史的生成成本，冻结训练时长上限。短步fixture不能证明专家成立。

**C比较**：同一160题E/B各独答一次，均只请求短答案；主指标官方答案EM差，辅以答案F1和技术完整性/长度/截断。不要求依据或来源，不以缺support/reasoning字段扣答案分。答案提取/规范化规则在V阶段预定，对B/E一致；后端缺失和语义错误分开，保留全部预定分母及原始输出。

**资格规则**：期望5–10pp不是必达阈值；核心是有意义的正差且配对不确定性支持。交流检查仅定位严重适配/接口破坏，不以分享质量筛专家。建议95%区间支持正差才进入“经校准专家”的主分析；否则只称候选，解释是样本不足、训练失败还是证据不明，不宣布没有专长。C160不能保证识别5pp；有效独立题更少或E/B分歧高时尤其如此。冻结结果解释规则后才跑C。

详细规格见[B0_EXPERT_VALIDATION.md](B0_EXPERT_VALIDATION.md)。R22替代旧两字段训练/三字段C规则：当前仅答案训练与校准。需要理由/引用时在后续讨论提示，分享质量不筛专家。现有三字段讨论状态机尚未改，真实团队运行前按最终协议对齐；不能直接拿它当仅答案资格测试。

R23设计审核补充：V按生成式答案EM、并列F1、再并列较早候选选模，候选时点预登记；C160当前一次、不自动扩样/换seed到通过。仅答案评分入口不得调用旧三字段解析器；该入口与训练器仍待实现。详见[审核报告](../../B0_DESIGN_REVIEW_20261031.md)，两轮自审后设计PASS、实际准备BLOCKED，未启动实现/计算。

**止点**：两次V训练尝试仍无优势，停止该专家构造路径，先判断可修训练问题或改用独立校准的异构现成模型；不加第三次/协作训练追涨分。C证据不足则不启动专家团队主实验。

### B1：损益发生在哪里？（必须）

**检验**：损失是E本来错误、互动后改坏，还是读出规则未保留正确意见；同时团队能否纠正E。

普通协议沿用户选择：4独答→分享冻结初答→4轮随机顺序、每轮每人一次、即时广播→4私有终答。主设置建议**初答完成后，中性公开谁在独立校准中表现更好**，不用“本题正确”或“必须服从”。这是本计划的设计建议，在运行配置中明记；身份隐藏是条件性扩展，未做对照不声称识别能力的因果作用。

| 读数 | 产生方式 | 排查什么 |
|---|---|---|
| E0 | E冻结初答 | 固定优势成员原始表现 |
| V0 | 四初答直接投票，无新生成 | 团队尚未讨论时，等权聚合已损失多少 |
| Eself | 复用E0，4次无队友消息重思+私有终答 | E自身生成机会增加后的漂移/改进 |
| Etalk | 普通讨论中E的私有终答 | 与Eself比较互动分支的影响 |
| Vtalk | 四私有终答投票 | 实际预定团队读出 |

V0/Vtalk统一使用gold-free答案规范化最高票、平票在最高票答案类中均匀选择；既报实际抽取，也报平票期望，避免偶然抽签主导小样本。不能用gold别名先合票。支持得分属于选中代表，不能当全队证据质量。Etalk作为“最终听E”的读数无需额外生成，是简单基线，不是自动提出新架构。

若团队初答额外要求解释，先报告D中该要求下的E0表现，再比较同要求的有/无消息分支。由输出要求变化即产生的损失，不归因队友；C仅答案优势与团队情境下优势分别报告。后续解释/引用具体约定仍待该阶段审定，不为此额外训练E。

**主要对比**：Etalk−Eself（互动分支对E的净影响）；Vtalk−V0（讨论相对静态聚合的增量）；Vtalk−E0及Vtalk−Eself（实际团队相对专家使用方式）。开发先同时看，确认阶段根据C1预测冻结一个主对比，其余辅助，不在H看完后挑最显著者。

**解读**：V0低而Vtalk未进一步降低→优先检查整合/读出，不能说讨论带偏；Etalk<Eself且有具体错误进入轨迹→支持互动损害；两分支都漂移→个体重思解释仍在；E初错且Vtalk改对→有益纠错事件，须追消息才能归因某成员。无损害也保留，可能是此设置的边界，不换题制造现象。

### B2：从真实轨迹选瓶颈，不先铺满原因实验（必须分析）

先审D8程序，再累计D32。记录原始事实/消息、实际收件、之后的推断和终答；正确答案本身不是有效证据的证明。先抽取具体事件，再标观察位置和候选解释，允许多处/UNKNOWN。

| 观察位置 | 足够具体的可查证迹象 | 不能仅据此断言 |
|---|---|---|
| E自身 | E0已错或论据无效，其他成员没有有效纠正 | 全部是团队拖累 |
| 分享 | E0/早期推理有有效依据，但公开消息遗漏/歪曲；区分“没说出”与“根本没产生” | 只因E答对就说它掌握了未表达的知识 |
| 接收/应用 | 正确关系确实送达，后续复述或使用与之不一致 | 直接读出模型内部理解/信任 |
| 同伴干扰 | 某条错误意见后出现相同错误，且原资料可核对 | 时间先后等于因果，或一律称从众 |
| 最终读出 | 正确终答仍存在，却被票选/平票/字符串差异舍弃 | 专家一定被说服了 |

覆盖成功利用、有益纠错、损失和无变化，不只收集失败。助手先核D，按用户决定不新增立即人工标注门槛。论文若报告某类事件频率/可靠性，再安排真实的独立双人核验：盲于分支效果/方法标签、保留分歧与UNKNOWN；两人核同一批完整题而非只读助手挑选片段。若只能一人，诚实降低独立性主张，不伪造一致性。

**选干预的依据**：事件可重复、证据能定位、可在不注入答案的情况下改变、与中心相关。最多选1–2项；若仅孤立/含混事件，不冻结一个“主要原因”。D32没有事件不证明没有问题；可先按原顺序扩余48或复核一个预定顺序seed，追加前登记范围，不无限扫设置。

### B3：针对所见瓶颈做最小因果检验（条件性必须）

只有B2支持时选一种路线，不把下面候选全跑：

- **分享/定位问题**：重排E原有消息、保留事实/否定/限定/结论，不补gold或新桥接；原消息、定向组织、等长通用布局控制。若新推导被添加，明确改称信息增补，不能当纯呈现效应。
- **收到但未核对/应用**：同一合法历史，在相同生成预算下用“对具体已有争议关系核对”替换普通指令；比较普通、等长通用重思、定向核对。不能把提示带来效果唯一归结为理解改善。
- **错误意见干扰**：在预先选定位置移除/改写真实错误消息，与通用消息删减或匹配长度的控制比较；这只能识别该消息处理包的作用。若要专门主张“多数/从众”，另需保持语义证据不变地操纵支持人数/社会线索，不能从答案一致率推出。
- **最终整合问题**：先用同一组成员终答比较普通投票、始终选E、仅根据当时可见理由的最小综合规则；同一finalizer/预算，若增加调用给普通综合相同机会。正确答案oracle只作上限，不能作为方法。

先在相同干预前历史分叉，固定输入/初答与后续顺序、配对多个采样seed，估计局部响应。随后重跑该位置之后**全部受影响发言和终答**，验证团队最终变化；只重写一个接收者终答是局部诊断，不当作全团队修复。干预在D选定，H前冻结。

全部题都纳入后续方法评价，不能仅保留E初对或定向干预获益题。gold可用于研究者的事后正确性核验，不能进入运行规则；诊断中按gold挑过的消息/事件，须标为oracle选择，不能直接宣称自动部署。是否训练专家协作能力仍保留、不排期；只有简单提示不足且实际瓶颈支持时另论证。

### B4：留出确认、解释与边界（发表所需，条件性）

在D之后冻结主假设/对比、操作、纠错容忍差、实际N/seed与预算。用H未见题配对确认普通协议与最小操作，保留Eself、初答聚合、“选E”等简单基线；再选**一个**有意义的新配置（第二个底座/规模，或独立任务及其重新校准专家），不同时铺开。另一个seed只是重复，不算新配置；同MuSiQue单模型结论不能直接推广所有MAS。

若只做分析论文，C1需稳定的受控响应/适用边界及独立确认，不必硬造新架构。若主张方法优越，必须超出简单提醒/选E或明确解释性能—纠错—成本的取舍，并选一个与最终机制最贴近的现有强协议作为比较；具体协议在选定机制后定，不现在凭名称堆基线。

## 5. 指标、统计与证据强度

答案EM为首要质量指标，F1为辅助；另报支持F1、可解析/截断/失败率、真实输入输出及thinking token（后端若提供）、GPU时长与峰值显存。Eself匹配E自己的额外5次生成，不等于全队总计算；方法成本优势必须给实测，不能仅比调用次数。

**正误转移必须各报分母**：E0正确→Etalk错误、E0错误→Etalk正确；E0正确→Vtalk错误、E0错误→Vtalk正确；无消息对应转移。条件保留/纠错率配合全题净收益，避免只挑E初对。各B初终答与共识度是辅助，不等于实际利用或从众。零事件及条件分母太小照报，不能给确定比例结论。

**统计单位**：题/已有资料关联组，而非一次发言。对所有分支复用同题配对；重复seed在题内聚合或分层重采样，不当作更多独立题。沿现有不看答案的关联定义固定组；按组bootstrap、组内保留全部题并按题加权，附按题敏感性；组少/大组主导时明示区间不可靠，不能靠重抽样伪装独立。C/D/H不在结果后重新分组。正式主检验限定一个，其他列探索或调整多重比较。

**样本量不是“跑200题就能发”**：配对二元差粗略最小可检效应约2.8×sqrt(q/N)，q为两条件不同正确性的比例，假设独立、双侧.05、约80%功效。若q=.30，N160/200/300/600约12.1/10.8/8.9/6.3pp；这不是结果，也不适用于交互/强关联数据。D32估事件率/分歧及其不确定性后，结合实用效应阈值测正式N；重复seed不能简单把N翻倍。可先预算100–300题探索确认，但只足以看较大效应，必要600题以上取决于实测/资源，不承诺现有时间一定足够。

**有效纠错的容忍差**：D后、H前确定可接受最大损失及检测精度。区间很宽不能说“不影响纠错”，不显著不等于非劣。若E初错太少，当前只能报告保留改善，不能承诺纠错不受损；需足够未筛选题覆盖或降低主张。

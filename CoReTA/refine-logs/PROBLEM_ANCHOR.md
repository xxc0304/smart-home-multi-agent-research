# CoReTA 设计锚点

日期：2026-10-18。以下锚点在本轮设计和审查中逐字沿用。

> 提高多 Agent 团队的协调与问题解决能力，让成员已有知识及协作中新产生的有用贡献得到实际利用；先把定向帮助、贡献检查、整合与应用反馈落实为三 Agent 可执行协议，再用已有论文采用的任务检验整体能力与互补作用。优先借鉴公开方法和官方代码，清楚区分复用接口与本项目的机制假设。能力与机制优先，成本如实记录，同成本优势与节约成本后置。本轮交付设计，不运行付费模型、训练或真实效果实验。

设计假设：当前解题状态可能为定向帮助提供依据，贡献的实际应用反馈可能改善后续协作。假设有效性待实验；不预设谁正确、谁总能帮上忙或某字段必然揭示真实困难。

建议约束：Python 轻量编排、三个独立上下文实例、冻结模型、无新增路由训练、任务和评分复用既有资源。实际服务端与计算资源尚未获知，设计配置不代表已获得端点、GPU或调用授权。

完成要求：提供逐组件接口和状态转移、字段来源、完整提示词、失败处理、任务与评分方案、对照与机制诊断、建议配置及运行顺序。设计就绪和效果成立分别判断。

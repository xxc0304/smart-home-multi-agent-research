# 构造协议示例

本目录所有回复均为人工构造，仅展示字段、引用、版本和状态衔接，不是真实模型轨迹，不作为能力或互补证据。

公开任务见 public_task.json。synthetic_trace.jsonl 包含三个独立初稿、初审、主解题者更新、定向请求、贡献、检查、实际整合和最终输出。request 是程序创建的事件，不另算模型调用；该路径共 9 次正常模型调用、10 条事件。当前候选从 v0 经过两次 lead_update 变为 v2。schema 的 base_version 表示调用/事件所针对的旧版本。

每个事件的路由信封由程序赋值。示例中的 resolved/supported 为构造的模型判断，不给它们赋予真值权限。

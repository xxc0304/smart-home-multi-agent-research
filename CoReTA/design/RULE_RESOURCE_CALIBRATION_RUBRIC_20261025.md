# 三项资源规则校准：离线口径

本口径不发送给模型。人工给定问题，只测新参数实例的资源支持推断，不测自主发现、团队利用或自然领域专长。

每份回答分别判断：目标是否可确定（与当前证据一致）、计算/规则适用是否正确、是否有害扩张、来源是否支持。无资源组合理表示未知，不计为虚假答案，也不因没有私有来源引用扣分。

| 局部项 | 有资源可支持的结果 | 无资源的合理边界 |
|---|---|---|
| 01换算 | (90-6)*1.25=105标准单位；解释工厂规则 | 无法确定系数、偏移及换算函数，不能默认90标准单位；条件性公式可接受 |
| 02库存 | Q8包含于Gamma24；独立需求42；可用64；都满足后剩22 | 不能确认Q8是否额外需求、损坏数及净库存；至少24+18=42可计算，但总需求需条件化。诚实缺信息不判错 |
| 03规则 | 实际R4、专用96节点满足含等号门槛；7<=9故允许 | R4条文未知，不能凭名字、广告或一般经验认定允许/不允许 |

除问题明确请求的目标外，库存可用数等相关正确局部推导记为附加有效内容，不强求每份回答都完整输出三个数。不把多列事实自动视为更好，不仅按答案数字匹配。

报告有资源的目标解决情况、无资源的合理未知/错误猜测情况及过度推断；不把两组“准确率差”定义成无资源合理未知也为错误。预期的信息可达性优势是受控构造，不足以证明真实专家能力。两重复每项只有两个样本，不做稳定优势或跨任务泛化判断。

继续规则：三项有资源均能至少一次正确运用规则，且没有任一项两次均有害误用，可称基本可用性信号；仍需复核，不能自动开主H1。某项均失败则报告该类规则应用不可靠，不把它从本批移除。无资源组也能解出时检查是否可由公开条件推出或是否有泄漏，不事后改题制造收益。

这只是12次小校准的预先有限决策口径，不是统计功效阈值。所有回答须逐条留依据，同一助手事后评分标明非独立盲评。

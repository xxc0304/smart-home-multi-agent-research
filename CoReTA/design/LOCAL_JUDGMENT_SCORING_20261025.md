# H1局部贡献评分口径与样例

版本：接口开发口径v1，未绑定正式评价集。仅离线评判，不发送给成员。不把人工示范当成模型结果。

## 1. 判什么

每次成员尝试是一个评分单位；重复生成不增加独立任务数。分别判断首轮选题/贡献、第二轮结果。技术接入状态单列，语义错误不改成格式失败。

首轮两组共有口径：

- self_contained：能否依据任务和该成员原件理解问题/贡献，还是依赖被删去的“上面那个”等指代。
- relevant：是否与任务中的决定、要求或解题步骤有关。
- grounded_opportunity：当前成员是否有可见证据或可复查操作支持处理它。需要其他条件并不自动无效，允许条件性任务。
- assumption_error：是否把原稿结论或未确认事实作为问题前提。

不要求普通组必须用问句；不会因普通组没有question字段而扣分。

第二轮共有口径：

- support：supported / conditional_supported / unsupported / unclear。来源匹配不自动得到supported。
- scope：preserved / overstated / misplaced / unclear，检查对象、时间、量词、用途及条件。
- task_value：new_or_corrective / redundant / irrelevant / unclear。贡献应补足或纠正任务依据，不要求推荐完整答案。多一句正确但无作用的常识不算new_or_corrective。
- harmful_part：是否引入无依据的排除、虚假保证、错误计数或错误来源评价。正确部分和有害部分分别记录，不相互掩盖。
- pass：justified / missed_opportunity / unclear / not_applicable。

首要筛查指标为全部成员尝试中交付受支持、范围恰当且有任务价值的局部结果的比例。同时报告有害结果、合理pass和遗漏，不能只以回答过的问题为分母。没有贡献机会的任务/成员占比另列，避免把合理pass理解为差的专家。

预先列出的任务审查点可用于报告覆盖与遗漏，但不是对所有可能有效贡献的穷举。审查点只给离线评分，不据金标将问题补给成员。

“局部结果有用”是潜在作用的离线判断，不等于整合者实际采用；H1不报告未经运行的团队增益。仅格式更整齐或引用更多不构成收益。

## 2. 人工评分样例

| 已用开发情形 | 假设输出 | 评价 |
|---|---|---|
| 011，S02报告厕所一小时内恢复，搬迁窗口两小时 | 若报告兑现，厕所问题可在窗口内缓解；不认证全天安全 | conditional_supported、scope preserved、有任务价值 |
| 同上 | 体育馆已完全就绪且全天不会停电 | unsupported、overstated、有害扩张 |
| 023，S01明确唯一通路周末关闭 | 可确认的通路在任务时间内不可用，不能虚构另一条路 | supported、scope preserved、有任务价值 |
| 同上 | 一条路不通不影响到达，肯定有别的路 | unsupported、misplaced、有害推断 |
| 023，S02允许本周电话临时预订 | 存在本周电话渠道；具体档期、容量和餐饮仍需确认 | supported、scope preserved、有任务价值 |
| 同上 | 该酒店本周六已预约成功 | unsupported、overstated，不因最终选项正确而改判 |
| 011，A4只见非候选College Hall关闭 | pass：当前资料不能区分三个候选 | justified pass，不算技术失败 |
| 011，A2有S02却只说“没有任何有关准备进度的信息” | pass | missed_opportunity，理由与所见信息冲突 |
| 任一问题 | “上述判断对吗？”作为第二阶段唯一问题文本 | self_contained不足；不得由宿主补正确对象 |
| 已正确处理的局部内容 | 再次准确复述，未增补或纠正依据 | 可supported但redundant，不算有效贡献增量 |

这些是评分解释样例，不是正式评价任务名单或参考答案包。

## 3. 评判程序

评判者获得任务及评判所需证据，结果匿名且不提供方法字段；文本风格可能暴露干预，不能承诺完全盲法。先判断每份输出，再做配对比较，保留原文和判定依据。

同一助手的开发标注注明身份；如果后续使用模型判分，需要固定模型、提示、预算并抽查，不能将模型判分视作真值。分歧保留，不按希望的方法方向裁决。

正式任务、重复数、差异判定和停止阈值尚未冻结，本口径不授权调用模型。先确认有限的筛查意义，不从极少配对声称稳定提升。

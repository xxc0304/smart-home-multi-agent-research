# 最小适配器实现决策（编码前记录）

1. 独立模块，不继承旧Runner；只处理ReviewPacket→观察账本→逐issue状态，暂不接DeepSeek/整题调度。
2. provider使用动态完整schema；本地按根包/逐issue分别验证，避免单问题字段错误污染其他issue。JSON错误、packet身份/候选身份错误、角色错属于整包失败。
3. packet由可信程序构造，adapter复制并预检；提交时传回请求关联ID和当前候选身份，模型不回写这些字段。
4. exact_equality仅解析规范整数/有理数；不可解析或语义不明不自动通过。历史supported若规范新旧观测矛盾，保持open；refuted须有新推导及当前核查，不覆盖旧值。
5. 无原case的issue仍需当前检查和独立理由；有原case需全覆盖。replacement=removed只作独立检查者的语义断言，不机械证明依赖消失。
6. 无可读材料、空完成条件、未知句柄、过期响应均保守阻断；所有原始输出与逐项错误保留。
7. 当前新反例先处理，所有current_checks仍逐项判定；任何该issue当前失败或不确定不能关闭。未关联的新失败阻止整个packet宣布完成，但不撤销无关issue的局部处理结论。
8. 本轮只有离线适配器，无付费调用；旧输出不可静默迁移为新契约成功。旧入口仍冻结，后续另行接入新调度。

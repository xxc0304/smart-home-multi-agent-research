# CoReTA

**Complementary Reasoning through Targeted Assistance**。研究目标是在多 Agent 推理中，通过定向求助、贡献检查和实际应用反馈，更好地利用成员专长，并检验团队能否产生超出预算匹配强单体的收益。

截至 2026-10-18：**设计阶段，当前架构 v0.2；尚无实现或实测效果**。本目录不将 HomeCoord-Bench 的历史结果作为本方法的验证。工作名及贡献主张仍待实验和进一步文献比较。

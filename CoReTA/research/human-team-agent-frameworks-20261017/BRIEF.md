# 人类协作机制与 LLM 多 Agent 框架：检索约束

日期：2026-10-17（Asia/Shanghai）。本轮只检索、阅读、比较和构思，不实现、不跑实验、不调用付费模型 API。

用户目标：从人类团队及社会组织的协作方式中寻找有广泛实际意义、可形成有效且有实质创新的方法框架的机制。避免过早限缩到专家投票、智慧家庭或小型边角任务；不预设必须提出 benchmark。

RQ1：人类团队、组织及集体决策有哪些具有理论或实证依据的协作机制？它们解决什么问题、在什么条件下失效？
RQ2：这些机制如何被现有 LLM 多 Agent 框架实现？哪些只是名称类比，哪些已经成为可执行协议、控制或学习机制？
RQ3：跨文献比较后，哪些有广泛意义的机制问题值得继续深化？与最接近方法相比，需要改变什么，才能形成实质增量？

检索角度：人类团队科学；LLM 框架的直接先例；反证、边界与方法学。主执行者另补组织设计、市场/制度协调及跨方向遗漏。

纳入：原始论文、作者/机构原始页面、官方研究与实践材料；区分人类实验、综述理论、LLM 实验、方法提案。每篇文献核对存在性及具体主张。预印本明确标示；摘要不足以支持的实现细节不补写。

研究边界：有先例不等于不可做；理论启发不等于创新成立；未检索到不等于无人做过。最终给出机会与直接竞争方法，不以模块堆叠或新框架名称充当贡献。不把人类心理属性直接当作 LLM 内在机制。

输出：人类机制—Agent 先例—适用条件—潜在改进对照；完整中文报告与来源核查表；少数值得深化的框架思路（未验证假设），不冻结实验协议。

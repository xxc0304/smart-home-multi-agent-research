这是可观察的工作到交付不一致及回到初答的局部案例。可排除这两条由名称—ID映射造成，也说明类似改变并非只能出现在LoRA专家中（本轮普通基础模型亦有）；不证明内部信念恢复、不唯一认定初答锚定、同伴影响或短答提示为原因。最后阶段仍保留初答/本地原件/公开历史且输出指令改变，这些是未分离因素。

不能把2/32或2/6当自然发生率：两个案例按旧故障挑选，两个变化也都在同一题同一条件。所有另外30条本批最后工作与私答名称相同，只说明这些路径没有出现实体更换，不认证整链推理正确。

## 对原研究主线的含义

1. 清晰输出接口能减少对“团队推理差”的误判；本次技术验收通过可以结束编号排障，不继续无界加例。
2. 团队读出正确可能掩盖成员交付不稳定。B和E/F团队分相同，但B的两位成员没保住自己四轮公开判断；只看团队准确率会漏掉它。
3. 这里没有专家被压制，反而是正确M1在讨论中帮助其他人；有专家团队架构应保留这种正面作用，同时检查最终提交可靠性。尚未显示超越M1私人作答的增量，两题均有M1天花板。
4. E/F都比私人好、但与普通讨论团队分相同；这两题不能作为屏蔽初答有效的主要证据。也不能因发现两条工作—私答改变就直接把它升级成论文核心或再次无限诊断。

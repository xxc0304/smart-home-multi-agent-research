# LLM 多 Agent 方法研究总览：检索简报

日期与截止：2026-10-18（Asia/Shanghai）。中文面向准备开展方法研究的读者；不预设某个候选方案是新贡献，不启动实验。

RQ1：现有多 Agent 研究实际控制哪些变量，解决哪些不同问题？组织、通信、聚合与学习怎样区分又怎样连接？
RQ2：代表方法具体如何运行，近年怎样从提示角色、固定流程推进到适应性与学习式协作？
RQ3：截至本轮可核验证据，哪些能力已有方法支持，哪些仍有条件或未解决？研究证据与评价不足在哪里？

范围：LLM 多 Agent 方法为主，包括任务执行、共同推理与混合体系。传统 MAS/MARL、ensemble、人类团队用于边界比较，不把所有传统结果等同 LLM 实证。独立多采样是强相关基线，不能自动叫作有交互的团队。

检索视角：组织架构与通信；推理与聚合及反证；团队学习与可靠性；主执行者负责综述交叉校验、评测/方法学、资源和时间边界。每路至少两轮， primary sources 核验，记录原文访问层级及版本。三路文献任务是信息收集，不构成独立审查认证。

文献状态：期刊/会议官方页优先；arXiv 预印本明确标识，不以搜索排名认定SOTA，不使用尚未核对的作者自报百分比作通用结论。文献池以主题覆盖为准，无全库穷尽或数量排名主张。

最终产物：中文总览 REPORT.md、证据专题和阅读建议。总览以相同控制对象比较方法；一篇方法可能横跨多维，不强制互斥归类。每个主要方向尽量三项原始来源，稀缺/访问受限处说明。

# 局部应用对照的离线审核口径

不发送给模型，不作运行时正确条件表。此为开发诊断；标注为同一助手事后复核，不称独立盲评。

四份W0来自已用开发任务：011重复1文本稿、022重复1文本稿、023重复1与重复2文本稿。前三份官方选项错误，第四份选项正确；“正确稿”不表示其理由所有句子或候选能力均已验证。这是目的性选择，不是总体错误比例估计。

## 局部贡献

分开记录：原句是否准确保留、任务解释是否有依据、是否交付实际revision、是否真正改变W0、修改范围是否局部、是否具有任务价值。revision出现不等于贡献正确，文字变长不等于知识应用。整题重解与局部修订单列；若收益主要来自更多完整候选，不能归因为局部应用。

内容判断保留supported / unsupported / uncertain / irrelevant / no_change_justified。只看到“没有已知反对”不能改成“确定可行”。出于正确保留而pass可合理；没有交付revision是行为/协议采用情况，不是JSON失败。

## 任务边界

- 011：两小时搬迁窗口与全天使用不同；一小时内恢复设施不等于已经恢复，也不等于一定来不及。两小时备用燃料对全天使用的后果需结合停电条件，不自动推成所有情况下都不可用。College Hall非候选。
- 022：库存承诺、配送延误、当前库存报告分别判断。通路结冰桥倒塌的实际范围不能凭一般“一条路不代表全部路”忽略。满库存不独立证明全部48小时保障，也不能只因属私有信息而说没有补给证据。
- 023：only access road与某条普通道路不同；通常两周预约不自动是无例外禁令。本周电话临时预约允许，不等于已预约成功；没有餐饮许可不能由主办场所容量推出来。禁止餐饮与允许密封小吃的范围须区分。

## 最终解答

官方选项匹配单独评分。判断实质知识是否进入最终理由/方案，看内容和后果，不只看是否引用A2等作者。与贡献内容一致不等于已证明其因果作用，因为W0和编辑者自己的原件也可能已有相关信息。

分别报告：错误选项修复、原本正确选项保持/损害、有用局部内容保留、有效修改被忽略、错误修改介入、未处理争议及成本。全部16份主对比输出与48份成员贡献保留，不仅挑收益案例。自然产生的错误贡献若未出现，不能声称证明了对错误介入的鲁棒性。

完整原件6次诊断与主比较分开；它不看W0，故与主条件既有信息呈现差异，也有错误稿锚定差异。更高成绩不能单独证明纯协调损失。每题两次也不足以确认稳定个人上限。

本轮不判断完整闭环架构有效，不验证独立专长形成，不声称信息发现能力提高，不把4份稿或8次配对重复称作8道独立任务。

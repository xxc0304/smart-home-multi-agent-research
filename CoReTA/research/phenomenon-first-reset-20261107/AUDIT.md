# 对“现象优先”讨论的复审

2026-11-07。用户要求审核上面的讨论与分析。助手自审none/provisional，不是独立人工/导师意见。本轮核对原核心稿/实验计划、D80及100题结果，复算一份数值证据快照；无新模型生成、训练、C/H评估或旧评分改动。

**总判断：将当前优先级调整为现象核验与价值取舍是合理的；但最近的讨论有过度纠偏。已确认若干现象存在，尚未选定并充分验证论文主现象。不能说项目没有现象证据，也不能把研究流程固化为“频率完全确认之前不许做任何诊断干预”。** 本复审补充优先于DECISION.md中容易被读成严格线性门槛的表述；当前仍不追加方法改进批次。

## 1. 逐项审核

| 讨论中的判断 | 审核 | 准确口径 |
|---|---|---|
| 应优先确认有价值的现象，再投入针对性方法 | 保留 | 当前需要主现象的覆盖、语义口径、影响与适用边界，方法不能由少数可讲述的案例直接决定 |
| 我们现在没有确认任何现象 | 修订 | 专家短答优势、部分局部损害/有益纠正、某些团队性能缺口及高度同质性已有证据；尚未完成主现象取舍和机制/普遍性确认 |
| 必须先证明高频，才值得研究 | 修订 | 频率是价值的一部分；影响、稳定性、实践后果、专家相关性与相近研究增量共同判断，不设置任意发生率门槛 |
| 在频率充分确认前不能做干预 | 修订 | 少量解释性干预可帮助定义现象、区分自身漂移/互动/读出，与测量迭代。当前限制的是无充分对象依据的大规模方法筛选，不是禁止一切诊断操作 |
| 最近100题有研究顺序提前的问题 | 保留但限定 | 主读数是提醒的团队净增益，属于方法探索；未充分完成主现象取舍便投入整夜扩批，资源优先级不够合理。但有限方法试探本身可以有意义，不能因为结果为零就倒推设计必然无意义 |
| 工程审核通过等于科学准备充分 | 不成立 | 请求、预算、故障隔离通过证明能可信执行；不证明主现象成熟、操作真正改变了目标行为或贡献足够 |
| 需要继续普查 | 保留但要收敛 | 下一交付必须给证据成熟度、价值排序与推荐/放弃依据，不能无限增加审核文档、分类或题数而不作取舍 |

单独的来源更细证据：旧第70有公开正确区别未支配选择的候选；Ann Arbor有匹配私人正确/讨论错误；桥梁有普通先对及E随后恢复；Megadeth有专家末答不变而公开消息处理改变队友最终答案的有限受控病例。它们均不能由同题多次运行增加独立题数，整体语义频率与适用条件仍缺。

因此，上次“主现象未确定”的判断合理；若理解为“没有任何现象、此前都没分析”，则不准确。应区分：存在性、发生范围、原因、论文主现象选择四个成熟度。

## 3. 最近100题应该怎样评价

两个提示确实进入模型并有真实响应，主56逐题团队EM差为0，专家100题末答逐字不变，属于可信的有限负结果。工作目标粗状态不变来自助手核读标签，未有独立人工确认；不能拿它证明内部判断完全不变或关系核对一般无效。

科学问题在于：少数已有病例未形成足够清晰的主现象/区分预测，就以提高净正确率为目标扩成100题。前期审核充分检查了执行可比性，但对研究问题成熟度、真实操纵行为和扩批的信息收益把关仍不足。这个批次留下四组基线、全过程和负对照，不应抹去；其新增资源价值应与本可完成的覆盖核验比较，而不是只按“正结果/零结果”判好坏。

不能用用户要求过夜多跑题来解释科学取舍；选择什么问题最值得跑，仍需要助手给出证据依据。

## 4. 下一次实质交付及完成条件

仍优先离线处理既有资料，不追加方法提醒或GPU批次。交付一张能用于选题的**候选现象证据与价值表**，最多保留2–3个主要候选，输出明确排序、推荐及反对依据，而不是只积累失效分类。

处理顺序：

1. 明确可核对事件和匹配对照；沿用专家损害/受益、优势转团队、公开判断的采用与读出，避免新建庞大原因框架。初答变化、私人自身漂移、同讨论专家末答和独立专家参照分开。
2. D80与新56分别全量粗筛，结合已见语义等价/歧义线索及同分对照抽检，不只看EM变化行；对候选核读原文，写清实际覆盖和未判定项。定向病例只作存在/稳健性材料。
3. 报总题、有效机会、不同题、关联组、频率/损益与不确定性；支持、反例和未解决替代解释并列。语义未核完的候选数不冒充真实机制率，样本内频率不冒充目标总体频率。
4. 按后果、可靠性、可解释性、专家相关性与已有研究增量选择推荐主现象；若解释缺口阻碍取舍，准备最小诊断方案即可，不强等所有频率精确后才研究原因，也不自动启动方法扩批。

独立人工关键子集复核与具体文献增量比较仍需后续实际完成。助手可先推进离线证据表，不增设用户即刻填表/逐项批准流程。方法不是必需终点；稳健经验发现与边界也可形成贡献，但需具体证据。

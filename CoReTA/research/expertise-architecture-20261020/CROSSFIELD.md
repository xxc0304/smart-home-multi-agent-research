# CoReTA 的跨域机制：把专长差异转成可区分、可检查的证据

日期：2026-10-20。范围：跨域机制研究；未运行模型、未修改实现。以下架构与预测均是待检验的研究设计，不是已有实验结论。

## 摘要与研究问题

本文研究三个问题：RQ-C1，哪些主动学习机制能把“专家意见不同”转成真正有判别力的检验？RQ-C2，怎样利用互补信息，同时避免重复来源制造虚假多数？RQ-C3，当接收者弱于专家时，怎样让专长变得可用而不把说服力当成正确性？

文献支持迁移三个操作：选择检验、追踪证据重叠、把表达转换与求解分离。它们不共同构成一个已经得到证明的通用系统。建议优先研究“候选的局部后果→盲测→据结果更新”，把教学式翻译作为竞争架构；证据去重先作为所有比较都应满足的条件。真正困难的是产生**既能区分候选、又能由较弱接收者可靠检查**的任务。这一交集可能为空，必须把空集作为机制失效，而非再加一个 judge。

## 1. 检索方法与证据等级

采用 deep-research 方法，先冻结上述问题，再按主动检验、信息聚合、弱监督/教学三条视角串行独立检索。第一轮查 BALD、Bayesian experimental design、information diversity、prover-verifier；第二轮专查 model misspecification、oracle leakage、machine teaching/Bayesian teaching 和 DPVG 的假设。读取原论文 HTML/PDF 方法段，配合 arXiv、PMLR、作者机构页面核验题名、作者、年份。检索截至本日，未声称穷尽所有近邻。

证据区分为：已读方法的原始研究；仅作历史定位的元数据；本文提出的迁移推断。后两者不借用前者的理论保证。R-IDeA 的 PMLR PDF 访问失败，已改读其 arXiv 全文并用 PMLR 正式页核对新题名；这两个版本按同一研究计数，不作为独立支持。

## 3. 跨域机制一：选择区分候选的检验

### 3.1 从“谁说得好”转向“哪些观察会改变选择”

C1 的实质是把查询预算用于可消除的分歧，而不是笼统收集更多文本。与 C2 对照后，CoReTA 的迁移目标应进一步收窄：**只选择与当前最终选择有关、且存在可信结果通道的检验**。信息多并不意味着更接近正确答案；假设空间没有真解时，熵降低可使系统更自信地错。

本文建议维护少量实质候选 H，而非每个发言者一个候选。候选必须给出同一局部问题 q 下的预期后果 r_h(q)。定义可实现的、非 Bayesian 精确后验版本：

`score(q) = relevant(q) × discriminates(H,q) × checkable(q) / cost(q)`。

这里 `relevant` 检查结果是否影响答案或必要前提；`discriminates` 由候选预先承诺的不同结果计算；`checkable` 只能来自预先规定的可执行规则、可核查原文或独立局部求解记录，不能来自“我认为此检验可靠”的自评分。这是待检验的启发式 acquisition function，不冒充 EIG 或有保证的 Value of Information。

若要写规范的 VOI，应是 `E_r[min_a R(a|E) - min_a R(a|E,r,q)] - cost(q)`，但风险 R、结果分布和错误率若不可估计，就不能把 LLM 随口输出的数字包装成该量。最小方案只做可区分性排序，并单独报告它与正确修订的关系。

### 3.2 无最终答案 oracle 的执行

1. 各方先独立求解；冻结当前答案和关键前提，避免争论过程中候选随评语漂移。
2. 从真正冲突处提出一项局部检验；双方先提交各自预测，之后才展示结果。
3. 结果通道只用：代码/代数/有限枚举的实际输出、给定材料中的直接定位，或隔离上下文后接收者的独立局部计算。最后一种仍属于可错的模型证据，应单独标记。
4. 先依据结果排除被反例直接推翻的具体主张，再让方案作者修订关联步骤。某个小例通过只能提高有限范围支持，不能宣布全局证明完成。
5. 无判别任务、检验结果不确定、或两候选都不符时，保留未解决分歧并允许新候选；停止机制由预算/可用证据决定，绝不用隐藏真答案停止。

“没有最终答案 oracle”不等于“没有任何可验证锚”。完全没有可信观察、又允许所有代理共享同一个错误时，协议无法仅凭文本区分正确世界与一致错误世界。此时最多改善可审计性，不能承诺正确性提高。

## 4. 跨域机制二：按新证据贡献聚合，而非按发言次数

C3 讨论的是信息集合重叠；它与 C1 的分歧查询互补，却不是给每个 agent 一个固定权重那么简单。三个人复述同一条证明，在证据层面可能只有一次支持；两个答案相同也可能来自真正独立的推导。词面相似度、模型身份、同意与否都不能识别真实误差相关性。

可落地的保守迁移是建立轻量来源链：主张→直接引用/推导/工具输出→其前提。由同一来源派生的支持归为同一证据族，重复转述不增加票数。来源独立但共享同一未证前提的证据仍保留相关标记；来源不同本身不保证独立。**去重是避免重复计数的规则，不是创造可信度的规则。**

若有事先独立开发集标签，可离线估计按任务类型分层的误差相关性与能力；这不使用部署题答案。但样本小、分布变化、专长定义不清时，不应在线求逆相关矩阵然后输出貌似精确的权重。无标签场景只执行可观察的来源去重，不声称已估计潜在误差协方差。

这里还存在一个与“避免折中”有关的反直觉：C3 并未证明平均总是错。在高度重叠条件下，某些平均规则很合理。CoReTA 应拒绝的是**没有说明前提和损失函数的折中**。对于数值估计，经过校准的平均可能正确；对于互斥证明或分类答案，把两个结论拼合可能根本不是合法候选。

C10 进一步提醒，利用 meta-prediction 识别少数者并不是通用补丁。诚实报告信念、拥有真实信息、推理得出正确答案是三个不同性质。给 LLM 提示“诚实专家”不会自动实现机制设计中的激励均衡，也不能排除伪造来源与策略性选例。

## 5. 跨域机制三：把专长转换成接收者能做的局部应用任务

### 5.1 标准 PVG、DPVG 与 teaching 的分工

C4 让强 prover 学会生成弱 verifier 易检查的输出；C5 把 solver 和 translator 分开，避免“表达必须简单”直接牺牲 solver 的求解过程。两者都借助真答案训练，不能直接论证无标签的提示式协作有效。特别是 DPVG 的 translator 忠于 solver 的答案，意味着它不能承担自主纠错：若 solver 错了，忠实 translator 应保留错误答案并让其能被识别，而非悄悄改成另一个结论。

C6/C7 是另一条邻近路线：teacher 不是简单解释，而是选取对 learner 最有帮助的示例。然而 C6 预设可用真标签/解释和 learner 模型，C7 依赖 learner 对 helpful teacher 的采样意图推断。它们支持“接收者难度与选例重要”，不支持“专家出的简单题天然能验证专家”。

因此，下列三个目标必须分开记录：

| 目标 | 可以观察的证据 | 常见误判 |
|---|---|---|
| 翻译保留主张 | 翻译前后答案、条件与适用范围一致；可机械核对的字段先机械核对 | 最终答案没变，就认为每一步推理都忠实 |
| 接收者理解并会应用 | 接收者在未见标签/正确答案情况下完成新变式；按事先规则判断 | 抄写教师示例、认同教师结论就算学会 |
| 原主张得到支持 | 局部任务结果区分当前候选，且有明确从结果到原主张的逻辑关系 | 接收者做对一项例题，就认为专家整题正确 |

### 5.2 推荐审查的具体协议：盲做的区分任务

竞争方案是：专家保留原解，仅输出一个最小知识包——适用前提、局部运算规则、一个不含最终标签的应用问题。对手必须说明该问题为什么能区分两套主张，以及自己在该问题上的预测。接收者在不知道哪个选项属于“专家”、也不看预期答案的条件下独立解；之后按既定可检查锚比较结果。出题者不能同时垄断标签、判分与是否允许反例。

**玩具例子，仅用于说明协议：**双方争论平均后的方差是 `σ²/n`，还是 `σ²[1+(n−1)ρ]/n`。专家让接收者先处理两份完全相同的随机变量：`Z=(X+X)/2`。接收者可独立化简为 `Z=X`，再由已给定 `Var(X)=σ²` 得到方差不变。该例推翻“任意相关性下都按 n 缩减”的主张；它没有证明现实数据中的 ρ 值，也没有完成所有 n 的一般推导。此处的有用性来自代数锚、候选分离和适用前提，而非出题者声望。

为了检查“只是教会一个自洽谬误”，再由接收者或预设生成器给出一个改变关键前提的新变式；教师不得事后修改评价标准。新变式必须仍在接收者可处理范围。若只允许教师展示自己挑选的成功例子，结果更像 curriculum/knowledge distillation，不能称纠错。

### 5.3 两个决定迁移成立的假设

**存在难度降解。**复杂正确主张必须有一个接收者能检查的局部后果。某些识别/直觉任务不存在易于语言传递的证书；某些数学结论的所有有判别力检验都与原题一样难。DPVG 并未消除此可能性。

**局部后果能限制原候选。**容易任务也可能对两个候选给出同样答案，或只覆盖它们都正确的区域。有效选例要求 `低难度 ∩ 真实区分 ∩ 可信检查 ∩ 与原题相关`。不能把“简单”单独最大化。

若独立接收者只说“我理解了，可信”，便退回 C8 所揭示的 judge 问题；若翻译以后又让所有人按文风投票，C11 的修辞风险仍在。C9 要求匹配调用预算，避免把额外推理机会误归因于教学机制。

## 6. 三个竞争架构及可失败预测

以下是竞争选项，不建议一次叠加成多模块系统。都固定底模、总 token/工具预算、初始独立候选，并使用同一套结果检查规则。

| 候选 | 唯一核心操作 | 专长如何被利用 | 最适合的条件 | 可直接推翻其机制的结果 |
|---|---|---|---|---|
| A：分歧驱动的局部实验 | 选择一项双方预先给出不同预测的可检查测试 | 专家提供弱者原先不会想到的判别检验或前提 | 有代数、代码、有限枚举、原文定位等局部锚 | 测试可区分性明显提高，但正确修订没有改善；或随机测试同预算同样好 |
| B：来源去重后的证据选择 | 对重复来源只保留一次支持，依据有限来源链选择完整候选 | 少数专家独有的有效来源不被转述多数淹没 | 信息专长差异明确、来源可追踪 | 同一证据复制若仍改变裁决，操作未生效；去重虽生效但独立推导被误合并导致准确率降低 |
| C：保留原解的教学式翻译 | 专家将差异知识转成接收者盲做的低难度区分任务 | 专长通过可应用规则迁移，无需先接受整段专家论证 | 接收者能掌握局部规则，但无法直接检查专家原解 | 仅教师选题有效、接收者新变式失效；或错专家也能同样提高“通过率”并造成更多错误改口 |

初步优先级：A 为核心研究候选；C 是最值得与 A 正面比较的方向，区别是信息传递形式与接收者难度约束；B 先做便宜的基础对照，只有在重复来源确实导致失败时再独立发展成主张。把 B、translator、judge、debate 都加上后看到提升，无法归因哪个机制发挥作用。

### 6.1 最小识别实验与失效判据

1. **实际纠错而非改口**：统计初始正确→错误与错误→正确；同时记录保留正确少数意见、采纳正确新证据、无依据改口。只报最终准确率会掩盖保护与纠错的冲突。
2. **去除身份**：打乱所谓专家身份/姓名，保持内容不变。好机制应主要响应局部检验和来源；若随标签翻转，看到的是权威效应。
3. **消融判别性**：匹配长度与难度，把有效区分任务换成两候选都能通过的例题；若提升相同，证据不支持“通过区分实现专长利用”。
4. **消融可信锚**：区分机械可查、原文直接可查、LLM 独立计算三类；若只有更强 judge 的类别有效，应承认收益来自 evaluator 能力。
5. **教师可错**：加入错误知识包、失效适用条件、来源伪造或选择性例子；正确拒绝率应提高，而非只让接收者更会跟随教师。
6. **原解保持与纠错分离**：检查 C 的 translator 是否改了原答案。保真失败不能被最终答案偶然正确掩盖；接受修改必须归属于有证据的后续修订步骤。
7. **候选空间外真解**：全部候选初始均错时，允许创建新候选并报告频率。A 若只是更坚决地选初始集合，可能在此条件退化。
8. **复制与独立支持分开**：复制同一推导不应增加支持；增加一项真正独立且可验证的新推导则允许改变判断。纯语义聚类若都不响应，会错失互补专长。

这些是建议的实验，不是本轮已执行项目。最终正确性只用于离线评估，不进入协作检验选择、停止或裁决。

## 7. 与近邻重复的风险及应该保留的新问题

| 提案表述 | 主要重叠 | 真正值得额外识别的区别 |
|---|---|---|
| “多 agent 提问解决分歧” | QBC、BALD、普通辩论与主动澄清 | 查询必须有候选条件预测及可信结果；判别性是否解释正确修订 |
| “专家把解答写得弱模型能理解” | PVG、DPVG、知识蒸馏、解释生成 | 接收者实际盲做新应用，而非接受性评分；翻译是否保留原主张 |
| “挑最好例子教会弱者” | Machine teaching、Bayesian teaching、curriculum | 教师可错、learner 未知、无原题标签；能否避免传播错误目标 |
| “对专家加权、合并独立证据” | 专家预测聚合、information diversity、证据追踪 | 可观察来源重叠与不可观察误差相关的区分；独立来源是否真的带来纠错 |

因此，不宜把创新押在“引入 verifier/translator/teacher”这些角色。更有研究内容的对象是：**当原解检查难于接收者能力时，是否存在足够便宜且有判别力的应用任务，使接收者在错误教师也可能出现的条件下，既保留正确专长又拒绝错误知识。** 这一命题能失败，且失败原因可分为无适合任务、检验自身不可靠、知识包不忠实、候选遗漏四种，便于解释。

## 8. 回答研究问题与未决限制

RQ-C1：可迁移的是带预测承诺的主动检验；BALD 的熵目标不是可直接照搬的正确性评分。必须有局部可信反馈，并容许模型集合失配。

RQ-C2：先按来源与推导依赖去重，才能讨论互补信息。无标签单题无法可靠估计完整相关误差；“不同 agent”不能替代“独立证据”。

RQ-C3：DPVG 支持求解/表达解耦的结构，teaching 支持按接收者选择例题的思路；两者都未证明无 oracle 下的专长验证。CoReTA 可把它们变成盲做区分任务，但必须单独检验保真、会应用、支持原主张三个条件。

本轮未证明 A 或 C 必然优于已有多 agent 方法，也未完成全体近邻排重。尤其在没有可检查锚、所有有效检验都很难、或错误专家能操纵出题分布时，应预期机制收益消失甚至反向。下一步的价值在于对这些条件做识别，而不是加长讨论轮次。

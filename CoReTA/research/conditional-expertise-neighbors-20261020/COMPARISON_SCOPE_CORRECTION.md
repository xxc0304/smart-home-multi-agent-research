# 比较层级校正：思想前身不构成架构重复判定

日期：2026-10-20。用户指出上一轮将不同贡献层级混为排重依据。本记录校正研究判断，不修改运行实现或实验结果。

## SAT

重新核读原文 §2.1–2.2。SAT 的学习具体是固定模型团队在训练问题上反思、提出、评估和选择组织策略，冻结策略库后部署；策略包含角色、交流阶段、参与者与信息流。这里没有用基座模型参数训练替代协作架构。其主要贡献包括学习组织的过程，CoReTA 当前以解释特定失败机制并设计相应架构为目标，贡献路径不同。

SAT 已部署局部贡献挽救和互补修复，仍值得比较具体执行动作，但共同目标、相似行为或个别协议相似均不足以判定整套架构重复。后续比较分别报告组织策略取得方式与运行时知识/控制机制，不能仅凭其中一轴宣布无创新。

来源：https://arxiv.org/html/2609.22682v1 ，§2。

## AAMAS 2012 条件论证及 DAREC2

2012 论文属于传统符号多智能体研究，输入是形式化逻辑知识库；广义上属于 agent，研究设定与当前 LLM agent 有实质差异。它直接提供条件组合思想及形式操作的前身，适宜作相关工作和设计资源，不应仅凭概念同源就当作现代 CoReTA 架构被覆盖的直接证据。DAREC2 同理属于形式执行先例。

从这些方法迁移到不完美自然语言成员，若具体解决条件发现、语义关系取得、可错支持和修订控制，可以形成方法贡献；仅更换底层载体或给旧过程换名，则不足以说明新增内容。当前候选仍处设计阶段，应评价潜力与待解操作，不使用完成论文的证据要求否定候选本身。

来源：https://www.ifaamas.org/Proceedings/aamas2012/papers/4C_2.pdf ，§2–4。

## 当前判断

保留条件化专长组合主线。现有检索不支持“整体架构已被覆盖”的判断，也不足以确认最终投稿贡献。下一步在一份完整设计中阐明失败解释、交流对象和运行时控制，再对已发表方法逐动作检查；不要求每个组件独立首创，不继续以概念相似不断推翻研究主线。

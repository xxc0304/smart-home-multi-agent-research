# MedAgentAudit v1 精读

- 版本：arXiv:2510.10185v1，2025-10-11。后续 v3 的标题、作者顺序和实验设置不同，不能混用。
- 原文：https://arxiv.org/html/2510.10185v1
- 问题：仅靠最终答案准确率，是否会漏掉医疗多智能体协作过程中的失败？
- 与 CoReTA 的关联：跟踪初始分析中的关键信息是否出现在后续综合与决策中；但被分配专家角色不等于已证明具有真实任务优势。
- 方法概览：生成协作日志，人工开放编码并建立失败类型，再用审计 agent 做定量分析。关键证据由审计 agent 判断，文本中出现也不等于证明它被因果性使用。
- 原文有待核对的不一致：正文称 3,600 条日志、300 条先导样本；Figure 1 分别标注 6×6×200 和 6×6×50。阅读结果时需继续检查样本口径，不将图中的数字直接当作正文样本数。
- 仓库：code/ 克隆的是当前公开仓库，其 README 对应较新的版本；尚未验证能否复现 v1。

## 精读路线

1. 问题动机与观察单位。
2. 日志生成、失败分类与审计流程。
3. 关键证据单元的识别与保留率，核对审计提示词和限制。
4. 数据集、模型及样本数口径。
5. 观点变化、协作质量与冲突处理的测量。
6. 主要结果、对照及因果解释边界。
7. 对 CoReTA 的启发与已做工作的重叠。

# 当前状态与交接（2026-10-18，v0.3 设计交付）

## 目标与优先级

通过协作组织提升多 Agent 团队的协调与问题解决能力，发挥成员已有知识与协作中新产生的贡献。能力及互补机制优先，成本如实记录，同成本优势和节约成本后置。

## 已完成的设计

当前采用 [v0.3 设计入口](design/v0.3/README.md) 和 [完整组件规格](refine-logs/FINAL_PROPOSAL.md)。四个核心组件为共享工作状态、定向帮助、贡献检查与整合、应用反馈；程序调度器只负责结构、版本、调用和停止，不判断真假。

第一版候选为三个独立上下文实例：A0 维护当前方案，A1/A2 均可帮助、检查或提出替代解。建议同用 Qwen3-32B 非思考模式；固定初审，最多两个工作轮。已明确消息和载荷、角色可见信息、版本事务、阶段提示词、故障降级、最终输入包及日志。

这些是本轮依据公开实现提出的可实施默认值，不表示用户已逐项确认，也不表示它们经验最优。v0.2 作为历史草案保留。

## 任务与验证方案

详见 [实验协议](refine-logs/EXPERIMENT_PLAN.md) 和 [跟踪表](refine-logs/EXPERIMENT_TRACKER.md)。

- 开发：GSM8K train50、MBPP sanitized train50；首轮真实开发试点建议各10题、一个重复。
- 正式评价：MATH-500 全500题、HumanEval/Plus 全164题，三个完整重复。
- 参考条件：单体、自行反思、独立汇总、静态讨论；主比较 CoReTA 与静态讨论。
- 机制：通用帮助、无显式应用记录、预定位置的贡献内容替换；配套下游变化和离线核对。
- 第一版无在线工具；金标准、参考实现和隐藏测试只由离线评分端持有。
- 全部规模与模型设置为设计建议，尚未发出任何模型或训练调用。

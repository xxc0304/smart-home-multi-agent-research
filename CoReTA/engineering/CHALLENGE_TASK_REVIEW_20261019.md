# 未试训练任务的挑战集复核

日期：2026-10-19。用途：上一轮六题三份初稿全对后，从本地GSM8K/MBPP训练源中筛选新的、多步或算法性任务。它们仍属于开发诊断题，不用于正式基准估计。

## 预先筛选规则

- 排除固定development-20261019题集及此前已运行的任务ID和重复题面。
- 检查与完整MATH-500/HumanEval+提示无重复；正式评价母集不被改动。
- GSM8K候选优先考虑官方解答中有多个明确运算步骤的题；MBPP候选优先考虑非平凡算法实现及至少三条原测试的题。
- 选择后、模型生成前，逐题核对题面与官方答案/原测试。若表述或期望输出有实质歧义则不纳入。
- 不查看任何CoReTA/对照条件的运行结果来选题。复杂度筛选只是开发集难度校准，不保证三份初稿会失败。

## 冻结任务及人工核对

| 任务 | 题面—评分核对 |
|---|---|
| `gsm8k/train/310` | 六名员工、工资率、工时和10%工资税均给定；逐类工资求和后加税，单位和时间范围一致。官方解答按工资总额的10%计税。 |
| `gsm8k/train/3750` | 每个娃娃45秒；每个娃娃配2鞋、3包、1套化妆品、5帽；各配件10秒。题面明确总产量和时间单位。 |
| `gsm8k/train/7446` | 男女比、总人数及各自喜欢篮球比例给定；求不喜欢者占总人数百分比。 |
| `gsm8k/train/5129` | 两位访客各拿每类水果的五分之一；数量、分配次数和剩余总量均明确。 |
| `mbpp/train/721` | N×N矩阵路径从左上至右下，只能向右/下。任一路径包含相同的2N−1个格子，最大平均值等价于最大路径和除以2N−1；原测试期待数值结果。 |
| `mbpp/train/751` | 检查数组表示的最小堆；使用标准层序数组表示和布尔结果，三个测试覆盖合法及子节点次序违规。 |
| `mbpp/train/622` | 两个等长已排序列表的中位数；测试给出各自长度参数并期待合并后中位数。输入、函数接口和数值输出一致。 |

新任务集由冻结Parquet源文件生成；生成Agent只接收公开题面、函数入口和参数个数，不接收数学答案、代码参考实现或隐藏测试。评分使用原答案/断言，不做编辑或后验过滤。

## 限制

这些题比上一小组有更多运算步骤/算法逻辑，但这不保证模型会失败。若三份初稿仍都通过，就记录为“无恢复机会”，不把条件最终分数相同说成架构无效或有效。单seed、小样本结果只用于诊断。

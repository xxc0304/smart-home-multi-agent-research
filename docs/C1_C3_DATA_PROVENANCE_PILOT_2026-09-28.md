## 正式数据集生成协议草案

1. **先定义证据层级。**离散状态和权限任务可评命令冲突；用电任务先说明容量实施点并给设备档案；持续热／空气质量任务必须另有可复现后端或联合轨迹。没有来源的参数可留在 `synthetic_stress` 子集，不得与有物理依据的样本混算部署结论。
2. **先选独立家庭／设备配置，再抽任务。**每个配置保存设备能力、功率或时长来源、初态、Agent 可见信息、动作生命周期。参数取值规则在看策略结果前固定；除有依据的参数区间外，探索网格明确标为人为压力条件。多条参数变体在统计时仍属于同一个基础模板。
3. **生成配对与非临界样本。**每个冲突条件对应一个只改变预定因素的可并行或非重叠对照；同时包含明显不冲突、明显冲突和边界配置。正式频率加权只有取得住户／设备事件分布后才定义，不能把研究者平衡采样当成家庭实际发生频率。
4. **先验可行性检查与独立审核。**验证单动作可执行、联合任务存在可行安全时序、目标没有被外部事件代做、动作开始／完成效果一致；两名审核者在不看策略结果时复核任务自然性、来源和最强反例。若修订影响结果解释，保留旧版本并让全部策略在新版本重跑。
5. **冻结版本后比较基线和模型。**在相同可见信息与安全门控下比较独立执行、设备锁、容量规则、状态再验证、中央 Agent 和多 Agent；记录过程安全、必要服务、首动作与完成时延。真实模型提案应实际采样，真实并发延迟应单独测量；固定提案回放只用于隔离协调变量。
6. **留出配置验证。**将部分设备配置、任务组合和参数范围留到方法确定后评估。若结论只在一个人工阈值附近成立，报告为机制现象；若跨配置稳定出现，才讨论一般性的协调价值。

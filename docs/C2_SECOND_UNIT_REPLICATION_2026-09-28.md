# C2 实测背景第二单元复核

日期：2026-09-28。状态：按预定规则完成的第二个匿名宿舍单元复核；属于 C2 背景证据，不是 Agent 协调实验或因果效果验证。

## 结果

在同一 Figshare 数据集的第二个改造前匿名宿舍单元中，使用与第一单元相同的筛选逻辑再次找到了“窗户由关转开、供暖功率大于 0.1 kW、室外温度低于室内温度”的观测窗口。

第二单元共扫描 455,393 条可解析分钟记录，时间从 2021-08-02 10:21 到 2022-06-14 17:13。发现 56,315 个“任一窗开且客厅/厨房电暖器功率大于 0.1 kW”的分钟 bin；按完整的 15 分钟前序、供暖连续性、温差、入口门状态及周边门窗转变条件进一步筛得 18 个候选事件。它们是同一单元长时序中的分钟记录和候选窗口，不能当作独立家庭样本。

排名第一的代表性窗口发生在 2022-04-19 23:04：开窗前 5 分钟平均室温约 22.186°C，室外温度约 2.22°C，电暖器功率约 2.413 kW，CO2 约 850.946 ppm。另两个入选窗口发生在 2022-01-30 和 2022-01-21，室外温度约 −10°C，供暖功率约 2.44 kW。

第一单元筛得 4 个候选，第二单元筛得 18 个候选，说明相同的状态背景并非只在一个匿名房间中出现。但两个单元的联合状态分钟数相差很大，不能据此估计普通家庭的发生率，也不能把单元间差异解释为住户行为差异。传感缺失、窗户持续开放、房间布置和设备回路都可能影响计数。

## 数据异构发现

第二单元使用 `8/2/21 10:21` 形式的两位年份，第一单元使用可由原提取器解析的四位年份格式。提取器现已同时支持两种格式，并为每个文件独立记录 Figshare file ID、文件名、大小和 SHA-256。这个差异说明后续导入其他单元时必须先做字段与时间格式审计，不能把“同一数据集”理解为格式完全一致。

## 能支持和不能支持的结论

本轮可以支持：公开实测数据中，C2 所需的“寒冷室外、室内供暖运行、窗户开启”背景可在至少两个独立匿名单元中找到；因此围绕该状态构造多 Agent 通风—供暖任务具有现实背景，不是完全凭空设定。

本轮仍不能支持：开窗导致了多少 CO2、温度或能耗变化；协调策略能节省多少能量；Agent 应在何时关闭供暖；这种状态在普通家庭中有多常见。要回答这些问题，下一步仍需使用经过轨迹或实验校验的反事实环境模型。

# C3 电动车／热水器：共同安全门控下的异步提案顺序回放

日期：2026-09-27。状态：作者侧合成压力试验；不是设备校准结果、独立任务样本或新协调算法。

## 为什么做这一轮

此前书房灯／空调 C3 草稿仅能说明已知容量规则优于设备锁，还存在 0.5 kW 灯具缺少现实依据的问题。另有电动车充电／热水器的独立试验，已用能量守恒计算动作工作量，并保存五组 DeepSeek 提案调用耗时，但使用的是单独的排序脚本。这次把同一对任务的**历史调用耗时**回放进 HomeCoord 的统一事件模拟器，让所有策略经过相同的启动前安全门控，并在设备完成时才计目标达成。

输入为两种容量：6.0 kW（4.0 kW 充电＋3.0 kW 加热不能并行）、7.2 kW（可并行）；5 组历史提案耗时；6 种策略，共 60 个事件回放单元。动作内容由同一脚本提案固定，**本轮没有重放真实模型的动作选择，也没有新 API 调用**。这 5 组只改变调用耗时，仍是一种任务模板，不算五个独立家庭情境。设备功率、效率和截止时间都是已明示但未经设备校准的压力条件。

参数证据按[来源核查表](C1_C3_PARAMETER_PROVENANCE_2026-09-27.md)分级：美国能源部页面只支持 4.0 kW 充电处于二级充电功率数量级；A. O. Smith 所查产品是 40 加仑、3800 W，**并非**本试验的 100 L、3.0 kW 热水器；6.0/7.2 kW 全屋容量、设备型号、效率和用户期限没有现场来源。公开页面提到的 7.2 kW 充电设备功率不能作为 7.2 kW 全屋容量的证据。

第六种策略是透明的 `CapacityAwareDeadlineCoordinator` 强规则：对已经发布但尚未返回的更早截止任务，若**公开的任务额定功率上界**与当前任务相加可能超过当前容量，就等待该提案再按截止时间安排；若已知可并行，就立即放行当前提案。缺少额定上界时保守等待。上界与环境中的真实功率分开存放，但本轮两者取相同的假设值，因此没有测试额定误差；它不是本文提出的新算法。

## 结果

| 条件 | 无提前协调／设备锁 | 容量约束先到先安排 | 始终等候＋期限排序 | 容量感知等候＋期限排序 | 单主 Agent 串行 |
|---|---|---|---|---|---|
| 低容量 6.0 kW | 共同门控拒绝一项任务，全部服务 0/5；无超限 | 两项服务 5/5；均按时 4/5 | 两项服务且均按时 5/5 | 两项服务且均按时 5/5 | 两项服务 5/5；均按时 4/5 |
| 高容量 7.2 kW | 两项服务且均按时 5/5 | 两项服务且均按时 5/5 | 两项服务且均按时 5/5 | 两项服务且均按时 5/5 | 两项服务 5/5；均按时 4/5，暴露无谓串行 |

唯一“热水提案先返回”的历史耗时组，热水任务在 1244 ms 准备好、充电任务在 1424 ms 准备好。低容量时，先到先安排让热水先占容量，车辆约 **5 小时 38 分 47 秒**才充满，晚于合成的 5 小时 20 分出发期限；等第二项提案后按期限排序，让车辆约 **5 小时**完成，热水随后完成，两项均按时。高容量时原本可以并行，等待策略仍让首个安全物理动作从 **1344 ms** 推迟到 **1524 ms**，多等 **180 ms**，没有增加任务服务或按时率。

这形成一个可复现的**条件取舍样例**：低容量且提案到达顺序不利时，等待排序有价值；高容量时等待没有收益。透明容量感知规则在低容量取得 5/5 均按时，在高容量避免了这 **180 ms** 白等。它比“有冲突就协调”更准确，也说明只比较冲突率会漏掉安全策略之间的按时完成差异；但这个样例已被简单强规则解决，本轮不支持“需要新 LLM 算法”的结论。

## 可信度边界与下一步

本试验把此前单独调度器的物理完成/截止时间逻辑放进统一事件运行时，且共用同一最低安全门控，证明运行时能表达“安全但排序不及时”的机制。它依赖人为设置在排序边界附近的截止时间与未经设备校准的负载、效率和容量；调度器还直接使用环境接地的真实动作功率和持续时间，属于理想信息条件。5 组耗时来自同一模型、同一任务模板，且原始 API 调用是顺序进行后用于逻辑异步回放。因此 4/5、5/5 都不能推断现实成功率或估计家庭冲突频率。

下一轮应先审设备/回路参数来源、任务自然性和截止时间依据。若保留为合成压力子集，需与书房灯草稿分开标注，并扩展到不同工作量、不同容量余量及不同任务顺序；不能把同一模板的参数格点当成独立样本。正式强基线应保留容量感知期限规则，并实测它使用的信息、规则处理耗时和设备反馈耗时；还应测试额定功率上界有误或缺失时的表现。回归测试已验证：缺少上界时该规则保守等待；把充电上界从实际 4.0 kW 错报为 2.0 kW 时，它不再提前等待，充电超时，但共同门控仍阻止容量违规。这是单点敏感性检查，不是额定误差分布实验。只有在强基线之上存在稳定缺口，才考虑更复杂方法。

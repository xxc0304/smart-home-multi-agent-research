## 已知待决事项，审核者须独立判断

1. **C1：** 6 秒制冷、1.4 kW 和瞬时到 24°C 均为合成假设；能源请求“reduce peak usage”尚无峰值窗口或量化服务目标。设备最终开关状态与温度达标不能混记。
2. **C2：** 现有 18 冲突／18 对照连续模型提供环境状态后果，但换气速率、热交换系数、制热速率和能耗均未校准。3 个低换气／240 秒格点已由乐观下界证明不可行，应与协调导致的超时区分。领域审核应判断共同热状态上的实际干扰是否足以构成 C2、对照是否公平，以及结果能否只作为合成任务族。
3. **C3：** 书房灯 0.5 kW、空调 1.0 kW 和动作时长缺少设备／回路来源；本地另一份台灯调研资料只提到某款台灯 14–18 W，不能给本设备校准，却提示 0.5 kW 普通照明设定的现实性问题。容量阈值对专业 Agent 不可见，却对协调器可见。比较模型能力时必须解释这项信息差异；若无匹配设备依据，请判断应改成抽象容量任务还是换设备配置。
4. **C4：** 现有清洁动作不可取消，缺停机延迟、部分进度和恢复契约；只能评测状态失效及安全／服务取舍，不能称为局部修复。事件时点仍是合成设定。
5. **全组：** C1／C3／C4 草稿已加入 `strict-v1` 工具映射和运行时参数／权限检查，但尚未经过真实模型工具提案测试；当前每任务只有单一固定提案，不宜直接称为完整动作规划能力比较。C2 是分立物理探针，没有真实模型提案或统一运行时接入。已出现的期限均为合成压力条件，不代表真实住宅的截止时间分布；C1／C3／C4 事件草稿本身没有截止时间。评估时请区分家庭最终目标达成、每项必要 Agent 服务完成和过程安全；C1 的温度目标可以达成，即使关机任务从未执行。

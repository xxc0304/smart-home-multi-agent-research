# C2 连续环境模型与实测轨迹的相容性审计

日期：2026-09-28。状态：模型淘汰与证据边界审计；不是因果参数拟合，也不是协调策略主实验。

## 为什么做这一步

现有 C2 探针假设开窗时 CO2 以 2.5 或 5 ppm/s 下降，制热使室温以 0.025°C/s 上升，开窗热交换系数为 0.0015/s。此前这些值仅用于受控敏感性试验，没有实测校准。现在已有两个独立单元的公开轨迹，因此首先检查这些参数是否至少与观测数量级相容。

## 方法

从两个单元各自预先筛出的三个代表窗口中，读取开窗后的连续分钟 bin。仅在至少有两个连续开窗 bin、温度、CO2、室外温度和供暖功率均存在时计算净变化率。共六个窗口，其中五个能计算短时净斜率。

这项计算只检查“开窗且供暖运行时观测到的联合净变化”。由于开窗和供暖不是随机干预，供暖回路功率也不等于传入房间的热量，所以不能从净斜率同时识别开窗换热系数与制热增益。

## 结果

- 两个单元共六个入选窗口，五个具有至少两个连续开窗分钟 bin。
- 只有第一单元的一条可用窗口在开窗前 CO2 高于900 ppm；第二单元三个排名最高的候选均低于900 ppm。因此第二单元复现的是“开窗与供暖共现背景”，没有复现现有任务中“高 CO2 触发通风”的完整条件。
- 唯一可用高 CO2 窗口的观测净 CO2 变化约为 −0.0417 ppm/s。现有模型的 −2.5 至 −5 ppm/s 范围没有覆盖该值，数量级相差约60至120倍。
- 五个可用窗口的室温净变化率中位数约为 0.0000926°C/s，接近稳定；它只能约束“制热增益减去开窗热损失”的合成结果，不能分别校准两项。

室内温度和 CO2 在公开分钟表中由五分钟传感数据插值得到，相邻分钟并非独立测量。窗口实际开度、占用、内部热源和供暖控制未知，因此不能把 −0.0417 ppm/s 外推成普遍换气速度。它足以完成模型相容性否证：当前2.5–5 ppm/s不能因这份数据而升级为实测校准值。

## 对实验环境的决定

1. 当前 C2 连续模型继续保留为合成敏感性环境，状态保持 `uncalibrated`。
2. 以前得到的“等待关窗省电但可能超时”只说明某组合成动力学下存在该取舍，不能写成真实家庭规律。
3. 两个实测单元可用于初态、天气、功率和事件背景，不直接提供协调与不协调的反事实标签。
4. C2 若进入论文主要物理结论，需要干预轨迹（无动作、只开窗、只制热、联合动作）或经过独立验证的建筑/空气质量模拟器。
5. 在取得上述条件前，正式 benchmark 主表应把 C2 标为“合成物理子集”，并将 C1、C3、C4 的离散机制结果与其分开报告。

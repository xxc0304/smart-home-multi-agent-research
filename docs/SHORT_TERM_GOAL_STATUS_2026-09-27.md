## 已完成的作者侧短期工作

- C1、C3、C4 的 9 条隔离草稿通过结构、配对差异、工具签名、答案泄漏、容量边界和固定提案回放检查；草稿仍标记为 `proposed_revision_not_scored`。
- 五种策略、三次重复，共 135 次确定性回放；45/45 配置的重复轨迹一致。固定提案延迟为 300 ms，不含模型 API 和真实设备调用。
- C2 已作为第四类冲突纳入研究范围、场景稿和审核包。其连续环境结果与 C1／C3／C4 的事件矩阵分开报告，防止把不同仿真语义混为一个统计批次。
- 当前事件稿的目标范围是冲突与经过时间；它们没有硬截止时间，不将此视为数据缺陷。修正范围审计后，作者侧设计检查 104/104 项通过，完整测试套件现为 126 项通过。C2 的期限仅是合成压力变量，不代表已确立真实家庭 deadline 分布，也不计入事件矩阵。

## 进入正式冻结前的门槛

1. 两位审核者独立检查 C1–C4 的任务自然度、物理／安全语义、配对公平性和强基线；记录分歧，不以作者自审代替。
2. C2 需先确认是否属于真正的共同状态干扰；没有校准数据时，只能作为清楚标记的合成子集。
3. C1、C3 的参数要么找到外部来源，要么明确保留为抽象合成变量；C4 要么补齐有依据的动作中断语义，要么不声称局部修复能力。
4. 冻结草稿版本后再增加真实模型提案质量与延迟评测。固定提案回放只能隔离协调因素，不能代表端到端 LLM Agent 表现。
5. 只有在短期评测范围确实需要硬截止调度时，才单独设计 deadline 任务并做乐观可行性检查；不为现有任务随意补 deadline。

## 当前判定

短期目标的**内部可复现实验搭建与 C1–C4 机制覆盖已形成初版证据链**，其中 C2 已实测但仍是未校准的独立合成环境。短期目标**尚未全部完成**：独立领域审核、C2 物理校准／明确降级、C1／C3 参数来源以及真实模型提案评测仍未完成。现阶段足以与老师讨论研究问题和验证路线，不足以声称数据集已冻结、冲突定义已获外部认可或现实系统效果已验证。
